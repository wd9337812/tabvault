English

TabVault is a tab-session saver for Chrome: it stores the list of tabs open in a window so you can restore that window later. To be explicit: TabVault does not sell data or upload saved sessions to developer servers, and it has no server that stores session content.

What data exists, and where does it live?
A "session" is a title + URL list per tab, plus a session name and timestamp. Everything is written only to your own browser through the chrome.storage API. It never leaves your device, it is never synced to us, and it is deleted permanently when you remove the extension or explicitly clear the extension’s stored data. Optionally you can export that local data to a JSON file yourself; that file is created and kept by you alone.

Site icons (favicons).
When a session is saved, TabVault also remembers each tab's favicon address — the icon URL the site itself publishes. The panel shows those icons by loading them directly from the site's own origin. Icons hosted on another origin are omitted. No icon is fetched through a developer proxy or third-party icon service. The site hosting the icon receives a normal image request, including your IP address; the extension does not upload your session list.

Why does the extension request the permissions it does?
tabs — read the title and URL of the tabs in the window you choose to save, so the session can be rebuilt later. Tab data is read when you press "Save", for the tab-count badge, or for auto-backup and recovery when explicitly enabled. TabVault does not read browsing history, does not send browsing telemetry. When you explicitly enable Pro auto-backup, tab changes update a local window cache so a closed window can be recovered. This cache and all backups remain on your device.
storage — the local persistence layer described above.
alarms — a timer that lets the optional Pro auto-backup take a snapshot of the normal browser windows every N minutes; snapshots are written to local storage only.
sidePanel — shows TabVault's own user interface in Chrome's side panel.

Licensing & payments.
The optional Pro upgrade is a one-time purchase processed by Stripe (stripe.com) on Stripe-hosted checkout pages. Card details are handled entirely by Stripe and never reach us. When you buy, our small worker verifies with Stripe that the payment succeeded and returns a license key; the extension then checks that key locally in your browser. We do not receive usage telemetry from the extension.

中文

TabVault 是一款 Chrome 标签会话管理扩展：把某个窗口中打开的标签列表 保存下来，之后一键恢复。我们明确声明：TabVault 不出售数据，不向开发者服务器上传 保存的会话，也没有存放会话内容的服务器。

数据存在哪里？
一个「会话」就是每个标签的标题与网址，加上会话名称和时间戳。所有内容仅通过 chrome.storage 写入你自己的浏览器本地，永不离开设备，也不会同步给我们； 卸载扩展或明确清除扩展存储即永久删除。你也可以自行把本地数据导出为 JSON 文件，该文件 只由你保存。

站点图标（favicon）。
保存会话时，TabVault 会一并记录每个标签的图标地址（站点自己公开的 icon 地址）。面板展示时 直接向该站点自身的源加载图标；跨源托管的图标会被省略。不经过开发者代理或第三方图标服务。 图标站点会收到普通图片请求（包括你的 IP 地址），扩展不会上传你的会话列表。

为什么要这些权限？
tabs：读取你主动保存的那个窗口中标签的标题与网址，以便之后恢复。只在你点击 「保存」时，或为标签数量提示及你主动开启的自动备份与恢复读取。不读取浏览历史，不向开发者发送浏览遥测。 开启 Pro 自动备份后，标签变化会更新本地窗口缓存，帮助恢复关闭的窗口；缓存和快照均保留在本机。
storage：上述本地存储。
alarms：定时器，让可选的 Pro 自动备份每隔 N 分钟为普通浏览器窗口拍一份快照， 快照只写入本地存储。
sidePanel：在 Chrome 侧边栏显示扩展自己的界面。

许可与支付。
Pro 一次性买断由 Stripe 在其托管结账页处理，银行卡信息完全由 Stripe 管理，不经过我们。 购买后，我们的轻量服务会向 Stripe 确认支付成功并返回一个 License Key，扩展随后在你的 浏览器本地校验该密钥。我们不接收任何使用遥测。
