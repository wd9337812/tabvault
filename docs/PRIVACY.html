English

TabVault is a tab-session saver for Chrome: it stores the list of tabs open in a window so you can restore that window later. To be explicit: TabVault does not collect, transmit, sell, or share any personal data, and it has no server that stores user content.

What data exists, and where does it live?
A "session" is a title + URL list per tab, plus a session name and timestamp. Everything is written only to your own browser through the chrome.storage API. It never leaves your device, it is never synced to us, and it is deleted permanently when you remove the extension or clear your browser data. Optionally you can export that local data to a JSON file yourself; that file is created and kept by you alone.

Site icons (favicons).
When a session is saved, TabVault also remembers each tab's favicon address — the icon URL the site itself publishes. The panel shows those icons by loading them directly from the site's own origin, exactly as your browser does when it draws a tab icon. No icon is fetched through us or through any third-party service, and nothing about your sessions is sent anywhere in the process.

Why does the extension request the permissions it does?
tabs — read the title and URL of the tabs in the window you choose to save, so the session can be rebuilt later. It is read at the moment you press "Save" (or when auto-backup runs, which you must enable explicitly). TabVault does not read browsing history, does not track which pages you visit, and does not monitor tab changes continuously.
storage — the local persistence layer described above.
alarms — a timer that lets the optional Pro auto-backup take a snapshot of the current window every N minutes; snapshots are written to local storage only.
sidePanel — shows TabVault's own user interface in Chrome's side panel.

Licensing & payments.
The optional Pro upgrade is a one-time purchase processed by Stripe (stripe.com) on Stripe-hosted checkout pages. Card details are handled entirely by Stripe and never reach us. When you buy, our small worker verifies with Stripe that the payment succeeded and returns a license key; the extension then checks that key locally in your browser. We do not receive usage telemetry from the extension.

中文

TabVault 是一款 Chrome 标签会话管理扩展：把某个窗口中打开的标签列表 保存下来，之后一键恢复。我们明确声明：TabVault 不收集、不传输、不出售、不共享 任何个人数据，也没有存放用户内容的服务器。

数据存在哪里？
一个「会话」就是每个标签的标题与网址，加上会话名称和时间戳。所有内容仅通过 chrome.storage 写入你自己的浏览器本地，永不离开设备，也不会同步给我们； 卸载扩展或清除浏览器数据即永久删除。你也可以自行把本地数据导出为 JSON 文件，该文件 只由你保存。

站点图标（favicon）。
保存会话时，TabVault 会一并记录每个标签的图标地址（站点自己公开的 icon 地址）。面板展示时 直接向该站点自身的域名加载图标，与浏览器绘制标签图标的方式完全相同；不经过我们或任何 第三方服务中转，过程中也不会把会话信息发送到任何地方。

为什么要这些权限？
tabs：读取你主动保存的那个窗口中标签的标题与网址，以便之后恢复。只在你点击 「保存」时（或在你主动开启的自动备份触发时）读取。不读取浏览历史，不追踪你访问了什么， 不持续监听标签变化。
storage：上述本地存储。
alarms：定时器，让可选的 Pro 自动备份每隔 N 分钟为当前窗口拍一份快照， 快照只写入本地存储。
sidePanel：在 Chrome 侧边栏显示扩展自己的界面。

许可与支付。
Pro 一次性买断由 Stripe 在其托管结账页处理，银行卡信息完全由 Stripe 管理，不经过我们。 购买后，我们的轻量服务会向 Stripe 确认支付成功并返回一个 License Key，扩展随后在你的 浏览器本地校验该密钥。我们不接收任何使用遥测。
