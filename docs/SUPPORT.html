English

How do I open TabVault?

Click the TabVault toolbar icon — the panel opens on the right side of Chrome. Press Alt+Shift+S to save the current window as a session without opening the panel first.

Where are my sessions stored?

Only in your browser (chrome.storage.local). There is no account and no server. Uninstalling the extension deletes them, so use Export (Pro) before reinstalling or switching computers — Import restores the same file.

Restoring opens a brand-new window — why?

Choose whether to restore in a new window or append the saved tabs to the current window. Existing tabs are retained.

Auto-backup is not running

Auto-backup is a Pro feature and it is opt-in. Check, in this order:

1. The panel header shows a PRO badge (if not, activate your license key first).
2. In the panel's settings drawer, turn on Auto backup.
3. Chrome must be running. Auto-backup snapshots normal windows at the selected interval, initially every 15 minutes; incognito windows are excluded.
4. Up to 20 automatic snapshots are retained across all windows. Changing the interval updates the timer. Manual sessions are retained separately.

Some tabs are missing from a saved session

Only normal http/https pages can be saved. Chrome's internal pages (chrome://, the Web Store, extensions' pages) and PDF viewers opened by other extensions are skipped, because the browser forbids restoring them. Repeated URLs and pinned tabs are preserved.

License delivery

After payment, copy the license key from the confirmation page into the extension settings. Keep that page’s address to retrieve the same key again. License keys are not automatically emailed. 付款后从成功页复制 Key 到扩展设置中激活；保留地址可重新领取，授权不自动发邮件。

My license key is not activating

Keys are checked locally and are case-sensitive: paste the whole string (xxxx.yyyy, one dot, no spaces or line breaks). If it still fails, the key may have expired. Contact the developer privately through the GitHub profile to check the order and recover the key. Do not post license keys or payment references in public issues.

Refunds

Email your Stripe receipt from within 14 days of purchase and you get a full refund, no questions asked. Purchases older than 14 days are handled case by case. Refunds are recorded in the order service and refunded orders cannot retrieve a new key. Previously activated offline licenses are not automatically revoked.

中文

怎么打开 TabVault？

点浏览器工具栏的 TabVault 图标，侧边栏会在右侧打开。按 Alt+Shift+S 可以不打开面板直接保存当前窗口。

会话存在哪里？

只存在你的浏览器本地（chrome.storage.local），没有账号也没有服务器。 卸载扩展会一并删除，所以换电脑或重装前请用 Pro 的「导出」存成 JSON，之后「导入」即可。

恢复时为什么是新开一个窗口？

这是刻意设计：恢复会新建一个窗口并放入保存的标签，绝不会打乱你当前已经打开的内容。

自动备份没有生效

自动备份属于 Pro，且需要你主动开启。请按顺序检查：

1. 面板标题处有 PRO 徽标（没有就先激活 License Key）；
2. 面板设置抽屉里打开「自动备份」开关；
3. Chrome 需要在运行中，定时器会对最后一次活跃的窗口拍快照；
4. 改过间隔的话，到 chrome://extensions 点扩展的「重新加载 ⟳」。

保存的会话少了几个标签

只有普通 http/https 页面可以保存。chrome:// 内部页、 Chrome 应用商店页面、其他扩展接管的 PDF 页会被跳过（浏览器不允许恢复它们）。重复网址会合并成一条。

License Key 激活失败

密钥在本地校验、区分大小写：请粘贴完整字符串（xxxx.yyyy，中间一个点， 不要有空格或换行）。仍然失败可能是已过期，把密钥和 Stripe 订单号发给我们即可补发。
