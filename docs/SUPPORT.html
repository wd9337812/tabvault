English

Reading and language

This page describes TabVault 0.5.0. Choose Compact, Standard or Large in Settings for free. The default follows browser language, with English fallback; EN / 中 switches manually. Check your installed version because store review and distribution can lag behind this page.

Open and update

Click the toolbar icon. Chrome 116+ is required. Update the existing extension without uninstalling, which deletes local content. Alt+Shift+S saves the current window.

Activate or restore Pro

Use Settings → Explore Pro to buy. Purchases started inside the extension activate automatically after verified payment. If you closed checkout, open the panel and check payment status; avoid paying again. In purchase management, Restore purchase verifies the checkout email. If email recovery is not configured, use Have a license code? with your saved code or contact support privately. Website purchases and older extension versions can use the fallback code.

Local backups

JSON import/export is free. Old over-quota backups remain readable, restorable and exportable; the creation quota applies only to new manual saves. Free includes 3 projects, session notes/tags/pins, selected-page/group restore and duplicate skipping. Pro removes manual-session/project count limits and adds advanced organization, batch missing-page recovery, named launch plans and reviewed cleanup.

History and restore

Auto-backup is off by default. Enable it in Settings; Chrome must be running. The interval starts at 15 minutes and incognito windows are excluded. Free retains up to 24 hours and 50 snapshots; Pro up to 30 days and 500. Both have a total snapshot limit of 4 MB, so actual coverage may be shorter. Manual sessions are kept separately. Restore URLs, order and pinned state; Browser-group restore and skipping open duplicate URLs are available on Free. Project restore opens one window per saved session. Partial or skipped restores preserve the original session even with delete-after-restore enabled. Page form state is not saved.

Refunds

Request a full refund within 14 days of purchase using your Stripe receipt, by emailing support@tabplugins.top. Older purchases are handled case by case. Refunds prevent new server license retrieval; already activated offline licenses are not automatically revoked.

Contact

For bugs, purchase help, refunds or privacy requests, email support@tabplugins.top. Include the product name, extension version and a description. For an order request, include your Stripe receipt or checkout reference privately. Never send API keys or license codes. Replies within 2 business days.

中文

字号与语言

本页介绍 TabVault 0.5.0。在设置中免费选择紧凑、标准或大字。默认跟随浏览器语言，未支持或识别失败时用英文，EN／中可手动切换。商店审核与分发可能滞后，请核对实际安装版本。

打开与更新

点击工具栏图标，需要 Chrome 116+。直接更新原扩展；卸载会删除本地内容。Alt+Shift+S 保存当前窗口。

激活与恢复购买

在设置 → 了解 Pro 中购买，确认付款后会自动激活。关闭付款页后也可返回插件检查付款状态，请勿重复付款。“管理购买”中的“恢复购买”通过结账邮箱验证码核实。若邮件服务暂未配置，可在“已有授权码？”输入保存的授权码，或私下联系支持。从网站购买及旧版插件可使用备用授权码。

本地备份

JSON 导入导出免费；旧备份即使超过免费额度仍可阅读、恢复和导出，额度仅限制新建手动会话。免费包含 3 个项目、会话备注／标签／置顶、选页及分组恢复和跳过已打开网址；Pro 解除手动会话／项目数量限制，并增加高级整理、缺页批量找回、命名启动方案及预览后应用整理。

历史与恢复

自动备份默认关闭，在设置主动开启，Chrome 需运行；默认间隔 15 分钟，排除隐身窗口。免费最长 24 小时、最多 50 份；Pro 最长 30 天、最多 500 份，两者均受快照合计 4 MB 限制，实际范围可能更短。手动会话单独保留。恢复网址、顺序和固定状态；浏览器分组恢复和跳过已打开的重复网址免费可用。按项目恢复时，每个已保存会话打开一个窗口。部分恢复或跳过页面时，即使开启恢复后删除，也保留原会话。不恢复网页表单状态。

退款

购买后 14 天内可凭 Stripe 收据发送邮件至 support@tabplugins.top 申请全额退款；超过 14 天逐单处理。退款阻止服务器重新签发，已激活的离线授权不会自动撤销。

联系

问题反馈、购买帮助、退款或隐私申请，请发送邮件至 support@tabplugins.top。请注明产品名称、插件版本和问题描述；订单问题可在邮件中附 Stripe 收据或付款编号。请勿发送 API Key 或授权码。两个工作日内回复。
