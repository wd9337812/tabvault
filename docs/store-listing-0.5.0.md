# TabVault 0.5.0 商店文案

## English

Save up to 30 manual tab sessions in 3 projects for free. Add notes, tags and pins; search saved titles and URLs; restore selected pages, browser groups and pinned tabs. JSON backups and basic Markdown/link exports stay available.

Optional automatic snapshots are off by default. Free keeps up to 24 hours, 50 snapshots and 4 MB in total. Pro raises history limits to up to 30 days and 500 snapshots within the same total storage limit. Actual recovery coverage depends on saved snapshots.

Pro adds history differences with batch recovery, named launch plans across windows, cross-session cleanup and more session/project capacity. Review before acting; undo the last local data change.

Choose compact, standard or large text. Follow browser language with English fallback, or select English/Simplified Chinese. Data stays local; no extension usage analytics. Optional Pro is a $6 one-time purchase, with applicable tax shown at checkout. Purchases started in the extension activate automatically; email recovery and existing license codes are supported.

## 简体中文

免费保存 30 个手动会话、创建 3 个项目，支持备注、标签、置顶、搜索、JSON 备份和基本 Markdown/链接导出。选择标签恢复、浏览器分组和跳过已打开页面免费可用。Pro 增加历史差异与批量找回、命名启动方案、跨会话整理，以及更多会话和项目容量。自动快照默认关闭；免费最长 24 小时、50 份，Pro 最长 30 天、500 份，均受总计 4 MB 限制，实际范围以已有快照为准。

免费提供紧凑、标准、大字；默认跟随浏览器语言，识别失败或未支持时使用英文，也可手动选择。数据保存在本机，插件内不收集使用统计。Pro 每款 $6 一次性买断，适用税费以结账页为准；从插件发起购买后自动激活，支持邮件恢复和已有授权码。
